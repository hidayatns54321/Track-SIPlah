# Tracking SIPLah

Website Tracking Pesanan SIPLah untuk memantau data pesanan dan progres pengisian.

## Fitur

- Tracking data pesanan SIPLah
- Pencarian nama sekolah, NPSN, toko, dan PIC
- Filter Regional
- Filter Entity
- Filter PIC Sales
- Filter Status SIPLah
- Monitoring progres
- Validasi Qty SIPLah dengan Jumlah Siswa
- Validasi Total SIPLah dengan Estimasi RAB
- Export data ke Excel
- Sinkronisasi data dengan Google Spreadsheet

## Website

https://hidayatns54321.github.io/Siplah-Tracking/

## Teknologi

- HTML
- CSS
- JavaScript
- Google Spreadsheet
- SheetJS

## Sumber Data

Data ditampilkan secara langsung dari Google Spreadsheet yang digunakan oleh aplikasi.

## Catatan

Agar data dapat ditampilkan, Google Spreadsheet harus dapat diakses oleh pengguna yang memiliki link.
